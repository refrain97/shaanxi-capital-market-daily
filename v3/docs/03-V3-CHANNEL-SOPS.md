# V3 六频道执行规范

版本：0.3  
生效日期：2026-07-11  
适用频道：上市公司、证券私募、股权私募与拟上市融资、收并购、金融招投标、国企动态雷达

## 1. 通用频道规则

每个频道都必须按以下步骤执行：

1. 按来源优先级采集并保存原始记录。
2. 映射规范主体和别名。
3. 判断新事件、进展、回溯、重复或排除。
4. 回源核验关键事实、数字和时间。
5. 映射业务类型和重要性。
6. 生成一个主信号；满足条件时再生成业务线索。
7. 更新年度事件库和本次快照。
8. 通过频道特有强约束后展示。

频道可以没有新增，不得为填满版式制造内容。

所有频道共同遵守 `08-V3-DATA-PROVIDERS.md`：官方披露负责最终事实，Wind 负责主体、财务和股东等结构化数据，iFinD 用于独立交叉核验和补充发现，搜索与聚合仅用于发现。Wind/iFinD 冲突必须保留双方口径并回到官方来源，不得静默选取更顺眼的值。

## 2. 上市公司

### 2.1 目标

从公告复述升级为“公告事实、结构化数据、业务影响和跟踪节点”的统一视图。

主体池包括陕西辖区 A 股、陕西港股，以及经确认的陕西关联上市公司。完整口径和当前关联名单见 `07-V3-LISTED-UNIVERSE.md`。

### 2.2 主要来源

1. CNINFO 和交易所公告原文。
2. 陕西证监局辖区公司名录。
3. 港交所披露易、港股发行人公告和年报。
4. 指定陕西关联上市公司线索池及最新股东数据。
5. Wind 结构化数据与 iFinD 交叉核验。
6. 公司官网和监管公开信息作为补充。

### 2.3 事件类型

- 风险与监管：立案、问询、诉讼、冻结、违约、风险警示。
- 资本运作：定增/再融资、可转债、并购重组、分拆上市、股份回购、募投补流。
- 股东服务：减持、增持、质押冻结、权益变动、转让拍卖、限售解禁。
- 治理关系：董监高、董秘证代、财务负责人、章程治理、内控整改。
- 激励与员工：股权激励、员工持股、授予归属、行权、回购注销。
- 资金与财务：现金管理、融资租赁、授信贷款、担保、关联资金。
- 业绩与分红：年报、季报、预告、快报、利润分配。
- 经营与产业：重大合同、对外投资、产能项目、停产检修、资质许可。

业务重点严格按配置中的21个二级标签判定；风险、业绩或重大经营可以是“内容重要”，但不因此自动成为“业务重点”。

### 2.4 输出形式

- 今日信号：一个公告事项对应一个主事件和一个主信号。
- 财务数据表：营收、归母净利、现金流、毛利率、分红、同比和报告期。
- 资本事项表：金额、比例、股数、价格、期限和状态。
- 公司时间线：同一事项的公告、问询、回复、审议、结果和终止。
- 业务线索：按照 RM Dashboard 业务视角映射。

### 2.5 强规则

- 逐公司检索仍为主口径，关键公告必须读取 PDF 正文。
- 不同主体池必须显示 `L1/L2/L3` 和纳入原因，不能把关联公司写成辖区公司。
- A+H 公司按一个主体处理，公告按市场分别采集。
- 关联池严格执行强线索、持股大于10%和比亚迪/海格通信排除规则。
- 同一事项不能以公司、股东、子公司或产品词换名后重复展示。
- 不要求固定 4、5、6 条；宁可空缺，不填普通事项。
- 年报季报优先进入数据表，重点异常再生成信号。
- 跟踪项必须引用原 `eventId`，不能重写成第二个事件。

## 3. 证券私募

### 3.1 目标

从每日重复全年名单，升级为管理人、人员、产品和状态的前后快照差异与年度台账。

### 3.2 主要来源

1. AMAC 管理人、基金产品和注销公示。
2. 管理人官网、公开工商和监管信息用于重点线索交叉核验。

### 3.3 三类主表

| 主表 | 关键字段 |
|---|---|
| 机构变动表 | 登记、注销、异常、办公地、规模区间、实缴和状态 |
| 人员变动表 | 法人、实控人、高管、投资负责人、合规负责人、从业人数变化 |
| 产品变动表 | 产品、管理人、托管人、成立日、备案日、基金编号 |

### 3.4 差异逻辑

- 每次保存来源快照，与上一成功快照按登记编号、人员角色和基金编号比较。
- 只有新增、删除或字段变化进入本次信号流。
- 年度页保留全部当前记录和变更时间线。
- 今日无变化时只更新检查时间，不重复发布年内 27 只产品清单。

### 3.5 线索方向

- 新设和迁入管理人服务。
- 新产品备案、托管与机构服务。
- 高管、投资负责人或实控人变化。
- 注销、异常和存续风险。
- 重点人员履历和机构背景变化。

### 3.6 强规则

- AMAC 数据日期、抓取状态和接口限制必须展示。
- 注销管理人必须确认机构类型。
- 注册地与办公地口径分开保存。
- 全国数据用于背景，陕西相关变化和高价值团队才进入首页。
- 接口限额导致不完整时，累计值不得包装成完整统计。

## 4. 股权私募与拟上市融资

### 4.1 目标

建立陕西股权融资、产业基金、拟上市公司和 Pre-IPO 动态的新增频道，并与国企、并购和上市辅导联动。

### 4.2 主要来源

- 监管和交易所公开的辅导、审核、问询及上市进度。
- 企业、投资机构、产业基金和国资平台官方披露。
- 政府引导基金、产业基金和公开融资信息。
- 可信媒体作为发现线索，关键事实需回到企业或机构来源。

### 4.3 事件类型

- 股权融资、增资扩股、战略投资、产业基金投资。
- 辅导备案、辅导进展、申报、问询、终止或上市。
- 基金设立、管理人遴选、子基金签约和项目投资。
- 股权转让、回购、估值变化和融资失败。

### 4.4 输出形式

- 融资事件表：轮次、金额、投资方、估值、用途、状态。
- 拟上市主体表：辅导机构、阶段、最新节点、所属产业。
- 投资机构与基金关系。
- 业务线索：股权融资、上市辅导、并购整合、债券和综合服务联动。

### 4.5 强规则

- 传闻融资不得作为已确认事件。
- 金额、轮次、投资方未知时明确标注，不得推断。
- 同一轮融资的媒体报道、工商变更和官方披露合并为一个事件时间线。
- 项目进入并购或招投标时跨频道关联，不重复建孤立事件。

## 5. 收并购

### 5.1 目标

把写死的全年长图改造成可持续维护的案例库、状态时间线和交易结构数据。

### 5.2 主要来源

1. 上市公司和交易所公告。
2. 国资监管、产权交易和企业官方披露。
3. 港交所及其他权威披露。
4. 可信媒体只用于发现和补充背景。

### 5.3 事件范围

- 股权收购、资产收购、重大资产重组。
- 控制权变更、产权转让、增资引战。
- 资产出售、剥离、终止和交割完成。
- 陕西主体对外交易、陕西标的被收购和陕西项目公司交易。

### 5.4 状态机

`线索 -> 意向/筹划 -> 预案/草案 -> 审议/问询 -> 批准 -> 交割 -> 完成`

分支状态：`终止`、`失败`、`暂停`、`待核验`。

### 5.5 输出形式

- 今日进展：只显示新增节点。
- 案例库：今年全部唯一交易。
- 交易时间线：公告和审批节点。
- 交易结构：买方、卖方、标的、比例、金额、支付方式和估值。
- 跟踪节点：下一审批、付款、工商变更、交割或承诺期。

### 5.6 强规则

- 按交易关系生成事件键，同一交易进展不新增案例。
- 金额、比例和估值必须回源；未披露不得估算。
- 无新增时不重新生成并上传同一 7742px 累计长图。
- 年度页默认按最新进展和状态筛选，详情页再展示完整时间线。

## 6. 金融招投标

### 6.1 目标

在公告发布阶段发现证券公司可参与的机会，而不是结果阶段补录。

### 6.2 主要来源

1. 招标人、采购人和集团官方采购网站。
2. 陕西招标投标公共服务平台、采购与招标平台、公共资源平台。
3. 招标代理机构和政府采购平台。
4. 聚合页和搜索结果仅用于发现。

### 6.3 采集顺序

1. 招标、采购、遴选、征集和比选公告。
2. 变更、答疑、延期和终止公告。
3. 候选人、成交和中标结果。

第一轮按重点主体池扫描，第二轮按产品词、服务词和动作词组合补充，不能只搜索“证券”或“承销”。

### 6.4 项目状态

`待核验 -> 公告期 -> 报名/投标中 -> 截止待结果 -> 候选人 -> 中标/成交 -> 履约 -> 结束`

异常状态：`已截止补录`、`终止`、`漏检复盘`。

### 6.5 新增机会必填字段

- 发现日期、公告日期和公告阶段。
- 采购人、项目名称、项目编号和服务类型。
- 报名/投标截止日期、开标日期。
- 证券公司可投依据和资格要求。
- 官方正文、代理机构和联系方式等公开字段。

### 6.6 强规则

- 只有公告阶段且仍可响应的项目可以进入行动窗口。
- 截止日期未知时不得默认可投。
- 只看到候选或结果时标为结果进展或漏检复盘。
- 同一项目的公告、变更、候选和结果更新同一 `eventId`。
- 首页默认只展示活跃机会；历史结果进入年度项目库。

## 7. 国企动态雷达

### 7.1 目标

把省属、市属和重点区县国企作为客户主体持续观察，并与其他频道形成主体级联动。

### 7.2 主要来源

- 陕西省国资委、西安市国资委及相关监管公开信息。
- 集团和重要子公司官网。
- 官方采购、产权、债券和项目平台。

### 7.3 分类

- 资本金融。
- 项目资产。
- 风险治理。
- 产业经营。
- 综合动态。

分类只是浏览维度，首页是否展示由业务相关性决定。

### 7.4 业务价值过滤

优先信号：发债融资、基金设立、资产盘活、重大投资、项目签约、资本运作、风险事项、治理和关键人员变化。

一般荣誉、会议学习、普通慰问、宣传性活动默认进入资料库，不进入“今日重点”；除非与客户关系或具体业务节点直接相关。

### 7.5 强规则

- 同一新闻不能同时在今日重点和分类栏完整重复。
- 集团和子公司的主体关系必须结构化。
- 国企信号与招投标、融资、并购、上市公司事件按 `entityId` 关联。
- 7 日窗口是筛选视图，不是把旧新闻重新标为今日新增。

## 8. 跨频道联动

同一主体或事件跨频道命中时：

- 保留一个主事件或通过 `relatedEventIds` 建立明确关系。
- 首页选择业务价值最高的主信号。
- 频道页只显示该频道视角的短引用。
- 主体页展示完整跨频道时间线。

典型联动：

- 国企债券采购 -> 国企雷达 + 招投标 + 债券业务线索。
- 拟上市公司融资 -> 股权融资 + 上市辅导 + 主体雷达。
- 上市公司收购 -> 上市公司公告 + 收并购案例库。
- 私募管理人新产品 -> 私募产品变化 + 托管或机构服务线索。

## 9. 来源运行频率矩阵

| 频道 | 上午必查 | 盘后必查 | 定期兜底 | 来源失败处理 |
|---|---|---|---|---|
| 上市公司 | CNINFO 逐公司窗口、港股公告、L3关联池、PDF 原文 | 日内公告补抓、上午待核验 | 每次回溯至少 5 个自然日；季度复核港股和关联主体池 | 任一主体池关键来源失败时标记对应范围降级 |
| 证券私募 | AMAC 机构、注销、产品快照 | 延迟披露和重点对象复核 | 每周/月全量与本地事件库比对 | 旧 JSON 不得冒充本次成功 |
| 股权融资 | 辅导、融资、基金和主体官网新增 | 日内补充与正文回源 | 每周主体池和产业基金差异检索 | 媒体线索保留候选，不升级确认 |
| 收并购 | 最近 3-7 天公告和行动中案例 | 审议、问询、批准、交割和终止进展 | 每周年初至今差异、每月完整复核 | 无官方证据只保留待核验 |
| 金融招投标 | 公告、采购、遴选、征集栏目优先 | 变更、延期、候选、结果 | 每周重点主体和已截止待结果项目复核 | 公告源失败则不得声称无新增机会 |
| 国企雷达 | 重点主体官网和国资监管新增 | 日内资本、项目和风险事件补充 | 每周维护主体池、栏目 URL 和失效链接 | 单站失败标记来源异常，不用旧新闻替代 |

每个来源运行都必须记录抓取开始、结束、数据截止、记录数、错误数、重试、内容哈希和最后成功时间。只有执行了计划来源或明确降级，才允许生成快照。
