# V3 产品愿景与表达形式

> 文档状态：初始愿景记录。当前权威执行依据为 `00-V3-MASTER-SOP.md`、`01-V3-PRESENTATION-SPEC.md`、`02-V3-DATA-CONTRACT.md` 和 `04-V3-QUALITY-GATES.md`；发生冲突时以权威文档为准。

创建日期：2026-07-08  
版本：草案 0.1  
定位：日频两次更新的陕西资本市场机构情报产品

## 1. 产品定位

V3 不再以“日报长图”为主，而是以“情报信号”为主。

目标用户打开网页后，应先看到：

1. 今天新增了什么。
2. 哪些还有行动窗口。
3. 哪些只是结果进展或历史补录。
4. 哪些数据需要整理成表格。
5. 哪些是真正值得跟客户、跟主体、跟业务部门沟通的线索。

## 2. 更新节奏

| 更新 | 时间定位 | 内容重点 | 表达形式 |
|---|---|---|---|
| 上午更新 | 开盘前/上午 | 隔夜公告、招标公告、AMAC 变化、客户主体事件 | 轻推送、今日信号、行动窗口 |
| 下午/盘后更新 | 收盘后/晚间 | 日内补充、公告回源、数据表格、深度线索建议 | 数据整理、线索复盘、明日跟踪 |

V3 的页面应明确显示本次更新时间，避免把上午信息、盘后信息和历史补录混在一起。

## 3. 表达层次

| 层次 | 观众看到什么 | 适合内容 |
|---|---|---|
| 快速推送 | 一句话、状态卡、行动窗口 | 简单商机、截止提醒、今日新增 |
| 数据整理 | 表格、矩阵、排名、对比 | 年报季报营收表、公告数字、私募人员变化 |
| 线索建议 | 解释、判断、下一步动作 | 客户跟踪、主体沟通、业务机会 |
| 证据详情 | 来源、公告、PDF、原文摘录 | 关键数字和事实核验 |

## 4. 视觉方向

主页面可以更年轻、轻量、产品化，借鉴 minimal/product-card 风格：

- 主页面像情报入口，不像文件夹。
- 模块卡片清楚、轻盈、可探索。
- 内页保留 dashboard/BI 的高密度表格和筛选。
- 不再用一张很长的图承载所有信息。

V3 的关键词：

- 轻量
- 年轻
- 可筛选
- 有状态
- 有时间线
- 有表格
- 有行动建议

## 5. 统一状态

| 状态 | 含义 | 首页位置 |
|---|---|---|
| 今日新增 | 本次更新新发现、仍有意义 | 今日信号 |
| 行动窗口 | 仍能联系、投标、跟踪、响应 | 行动窗口 |
| 数据待整理 | 适合做表格/对比/排名 | 数据整理 |
| 线索建议 | 值得进一步业务跟进 | 线索建议 |
| 结果进展 | 已进入候选人、结果、落地阶段 | 结果进展 |
| 回溯补录 | 今天发现历史事项 | 补录区 |
| 沿用观察 | 无新增，仅保留累计观察 | 观察池 |
| 漏检复盘 | 本应早发现但结果阶段才发现 | 质量区 |

## 6. 各频道重构方向

### 6.1 上市公司

V1 问题：

- 冗余较多，同一个问题在多栏重复说。
- 信息很全，但不一定是用户最想看的。
- 年报、季报、经营数据适合做表格，而不是塞进长段落。

V3 改法：

- 每家公司每天只生成一个主 `signal`，多个栏目只引用摘要。
- 年报季报季节，优先做营收、净利、现金流、分红、费用等表格。
- 业务分类按照 RM Dashboard 口径组织，例如资本运作、股东服务、激励员工、资金财务、治理关系、风险沟通、业绩分红、经营产业。
- 输出从“公告复述”改为“数据整理 + 线索建议”。

### 6.2 证券私募

V1 问题：

- 视角偏陕西私募机构日更，业务解释空间还不够。

V3 改法：

- 视角更广：陕西私募机构、人员变更、管理人状态、产品备案变化、异常或注销追踪。
- 增加人员变更追踪：高管、法定代表人、实际控制人、从业人员变化。
- 将 AMAC 变化整理为“机构变动表”“人员变动表”“产品变动表”。
- 重要变化生成线索建议，而不是只做数据日报。

### 6.3 股权私募与拟上市融资

新增栏目：

- 陕西地区股权私募。
- 拟上市公司融资、股权融资、产业基金投资、Pre-IPO 动态。
- 省内重点产业链公司融资线索。
- 与上市辅导、并购、招投标、国企产业资本形成联动。

表达方式：

- 融资事件表。
- 拟上市主体观察表。
- 投资机构/基金关联图。
- 重点线索建议。

### 6.4 收并购

V1 问题：

- 长图不方便查看。
- 累计案例和今日变化混在一起。

V3 改法：

- 拆成“今日进展”“案例库”“时间线”“交易结构”。
- 每个案例提供状态、金额、交易对方、审批进度、最新动作。
- 长图改为网页表格 + 时间线 + 详情页。

### 6.5 金融招投标

V1 问题：

- 长图不方便查。
- 容易结果出来后才补录，不符合“公告期发现”的业务需求。

V3 改法：

- 招标公告首发捕捉。
- 重点展示投标截止日、开标日、采购内容、证券公司可投依据。
- 项目库用可筛选表格，不用长图承载全部信息。
- 结果回溯只做状态更新，不算新增机会。

### 6.6 国企动态雷达

定位：

- 客户主体观察入口。
- 与上市公司、收并购、招投标、股权融资线索联动。

表达方式：

- 重点主体卡。
- 7 日窗口事件。
- 客户联系入口。
- 主体事件时间线。

## 7. V3 最终形态

V3 应该是一个五层结构：

1. 主页面：今日情报入口。
2. 信号流：本次更新所有 signal。
3. 数据表：上市公司、私募、招投标、融资等结构化表格。
4. 线索建议：真正值得跟进的业务机会。
5. 证据详情：公告、来源、PDF、原始链接和校验状态。

一句话：

V3 不是“日报发布站”，而是“陕西资本市场日频机构情报系统”。
