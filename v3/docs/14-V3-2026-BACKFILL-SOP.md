# V3 2026 历史回填 SOP

## 统一范围

- 起始日固定为 `2026-01-01`。
- 截止日使用运行时实际日期，不用网页展示日期代替。
- 覆盖上市公司、证券私募、拟上市与股权融资、收并购、金融招投标、国企动态六个频道。
- 历史首次入库统一标记 `backfill`，不得写成当天新发生或当天发现。

## 四层完成状态

1. `RAW_COMPLETE`：主体和日期范围内的原始记录已采集，失败项为零。
2. `NORMALIZED`：主体、来源、时间和业务分类已规范化。
3. `DEDUPED`：同一事项的多份公告已归并为唯一事件和时间线。
4. `VERIFIED`：关键数字、状态和节点已读取官方正文并通过质量门。

任何频道只有达到第四层，才可以在页面声称“2026年完整回填”。覆盖台账保存在 `data/backfill/coverage-2026.json`。

## 上市公司顺序

1. 通过巨潮证券主数据解析 L1、L2、L3 共117家主体标识。
2. 分季度逐公司抓取全部公告，保存原始响应。
3. 依据八个一级业务和43个二级标签筛选候选事项。
4. 下载候选公告正文，提取数字、期限和主体。
5. 按交易、股东、激励计划、监管事项等稳定关系键归并事件。
6. 港股必须再与HKEX披露易核对，巨潮覆盖不能单独宣称港股完整。

## 运行

```bash
python3 v3/scripts/backfill_listed_cninfo.py --start-date 2026-01-01 --end-date YYYY-MM-DD --resume
```

脚本可断点续跑。已有完整季度不重复请求，存在错误的季度必须重新采集或进入缺口清单。
