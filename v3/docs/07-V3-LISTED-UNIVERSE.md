# V3 上市公司观察主体与陕西关联准入 SOP

版本：0.3  
生效日期：2026-07-22  
权威级别：上市公司频道主体范围依据

## 1. 当前口径

V3 上市公司频道使用三层观察池，当前基线为 `L1 85 + L2 14 + L3 11 = 110家`。

| 层级 | 名称 | 准入条件 |
|---|---|---|
| `L1` | 陕西辖区 A 股 | 陕西证监局最新辖区上市公司名录，且上市状态有效 |
| `L2` | 陕西港股上市公司 | 总部、主要办公地或主要经营管理主体明确在陕西，并逐家回源 |
| `L3` | 陕西强关联上市公司 | 在陕西有实质经营基地/总部，或陕西主体形成控制、重大持股、公司治理或同一控股集团产业关系；逐家人工准入 |

三个层级均进入公告和事件检索。页面必须显示层级及纳入原因；`L2`、`L3` 不得写成“陕西辖区上市公司”。

## 2. 准入原则

### 2.1 可以纳入

- 陕西存在总部、主要办公地、核心生产研发基地或重要经营平台。
- 陕西主体为控股股东、第一大股东，或通过持股、表决权委托、董事会席位形成控制或重大治理影响。
- 陕西主体与公司处于同一控股集团，且存在可以由定期报告或关联交易披露验证的产业关系。
- 其他不能由通用阈值判断、但经官方材料确认具有持续实质关系的对象，经人工复核后纳入。

### 2.2 不自动纳入

- 仅有低比例财务持股，且没有控制、治理或产业协同证据。
- 仅由信托计划、私募基金或其他金融产品持股，即使比例超过10%。
- 仅自然人股东、董事长、法定代表人或总经理曾在西安学习、任职。
- 仅有陕西销售、普通项目、临时合作或未经官方材料复核的搜索线索。

禁止继续使用旧规则：

```text
(线索强度=强 OR 陕西关联持股>10%) => 自动纳入
```

新规则为：

```text
候选线索 -> 官方材料回源 -> 判断公司级实质关系 -> 人工准入/排除
```

持股比例仅是证据字段，不再是单独准入开关。

## 6. 更新与页面规则

- `L1`：陕西证监局名录更新或上市状态变化时刷新；当前底表日期为2026-03-31，必须继续追踪更新。
- `L2`：至少每季度复核港股发行人主体、上市、停牌、退市、迁址和业务变化。
- `L3`：至少按半年报、年报和控制权变更披露复核一次；关系失效时记录退出日期。
- 页面分别展示 `L1/L2/L3` 数量、实际检索覆盖和关系类型，不使用写死的“117家”。
- 历史公告可以留在原始归档，但当前工作台、候选事件和统计必须按活动主体池过滤。
